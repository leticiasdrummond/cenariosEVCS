# Análise de Microrredes em Eletropostos com PV e BESS

## 1. Objetivo do Projeto
Este projeto implementa modelos computacionais para otimizar o dimensionamento e a operação de microrredes em eletropostos, considerando diferentes cenários de exportação de energia, níveis de CAPEX e riscos de disponibilidade da rede elétrica.

## 2. Como Reproduzir
- **Pré-requisitos:** Python 3.9+, bibliotecas: `pyomo`, `numpy`, `matplotlib`, `pandas`, `gurobipy` (ou outro solver).
- **Passo a passo:**
  1. Clone este repositório.
  2. Instale as dependências: `pip install -r requirements.txt`
  3. Execute o script principal: `python 2_codigos/subprogramas_analise.py`
  4. Os resultados serão gerados na pasta `3_resultados/`.

## 3. Catálogo de Subprogramas e Cenários

| Subprograma (Classe) | Cenário Principal | Parâmetro Chave | Saída Principal |
| :--- | :--- | :--- | :--- |
| `ExportProibidoSimulator` | Operação sem injeção na rede (`allow_grid_export = False`) | `P_trafo_cap_max` | Balanço de potência, SOC, análise de risco do trafo |
| `CapexSimplesSimulator` | Comparação CAPEX único (com/sem exportação) | `permitir_exportacao = True/False` | Lucro operacional, payback |
| `RiscoRedeSimulator` | Análise de sensibilidade à falha da rede | `niveis_disponibilidade = [1.0, 0.5, 0.1]` | Impacto da disponibilidade no lucro e dimensionamento |
| `ComparacaoRecursosRiscos` | Comparação de estratégias (PV-only, BESS-only, PV+BESS) | `niveis_disponibilidade` | Vantagem relativa, payback vs. risco |

## 4. Metodologia Científica e Conexão com o Código

A estrutura dos modelos segue uma formulação de **Programação Linear Inteira Mista (MILP)**. A tabela abaixo conecta exigências metodológicas a trechos de código.

| Exigência Metodológica | Implementação no Código (Exemplo) | Subprograma |
| :--- | :--- | :--- |
| **Função Objetivo** | Maximização do lucro líquido: `annual_profit - capex` | Todos |
| **Balanço de Energia** | `m.P_pv_gen[t] + m.P_grid_import[t] + m.P_bess_discharge[t] == m.P_ev_load_kw[t] + m.P_bess_charge[t]` | `ExportProibidoSimulator` |
| **Modelagem da Bateria (BESS)** | - Balanço de SOC com eficiência (`eta_charge`, `eta_discharge`)<br>- Restrição de não-simultaneidade (`y_bess`) | Todos |
| **Risco de Rede** | Redução da capacidade do transformador via parâmetro: `P_trafo_cap_max * nivel` | `RiscoRedeSimulator` |
| **Reprodutibilidade** | - Uso de semente fixa (`np.random.seed`)<br>- Parâmetros documentados em `exemplo_dados()`<br>- Versionamento no GitHub | Todos |
